# Funcionamento

1. O usuário arrasta 1 ou 2 PDFs.
2. O parser identifica o documento fiscal e, quando existir, o recibo/boleto.
3. Os dados são extraídos e validados.
4. O navegador configurado é aberto com perfil persistente.
5. O sistema faz login se necessário.
6. A nota-base do mês anterior é buscada para recuperar o RATEIO.
7. O formulário do Agilize é preenchido.
8. Todos os PDFs fornecidos pelo usuário são anexados.
9. O documento de referência é aberto em outra aba.
10. O usuário confere e envia manualmente.

A automação nunca aciona o botão final de envio.
